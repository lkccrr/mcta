McTa

格塔 · Meta Crystal Toolkit & Analysis

McTa 把 VASP 与 phonopy 的常见后处理收进一组 mt.* 命令：读原始输出直接出图， 参数与风格保持一致。

背景

  • 起点：能带、态密度、声子谱的读取与绘图散落在多份脚本里，参数与出图风格各不相同。
  • 做法：统一为一组 mt.* 子命令，读 EIGENVAL、DOSCAR、BAND.dat 等原始输出即可出图。
  • 范围：电子结构、晶格动力学、结构检索、准随机固溶体与磁性蒙特卡洛；除 mt.seek 联网外都在本地完成。

用途

  • 电子结构：mt.band 出能带与投影，mt.dos 出态密度，可计算有效质量。
  • 晶格动力学：mt.phband、mt.phdos 出谱与态密度；mt.ph、mt.ph3 查词条与流程。
  • 结构数据：mt.seek 检索并导出结构，mt.sqs 生成准随机固溶体，mt.skl 评估描述符重要性。
  • 模拟与脚本：mt.mc 跑磁性蒙特卡洛，mt.sh 调用随包脚本，mt.server 运行本地文件服务。

常用示例

用途命令
能带mt.band -i calc_PBE -d -z
态密度mt.dos -i calc -p d -x 0 30
声子谱mt.phband -i BAND.dat -l g m k g -d
声子态密度mt.phdos -i calc -z -x 0 0.6
结构检索mt.seek -c Ti-C -k 3 -n ti-c
准随机固溶体mt.sqs -c cell.vasp -a "Cu:0.5,Au:0.5" -x 4,4,4 -n cuau-sqs
描述符筛选mt.skl
磁性蒙特卡洛mt.mc -x 128 -y 128 -t 0 40 2
随包脚本mt.sh kb POSCAR 2 2 1
文件服务mt.server

统一约定

  • 参数一致：-i 指定输入目录或文件，-o 指定输出，-h 查看全部参数。
  • 输入原样：只读取 VASP / phonopy 的原始输出，不要求先转格式，也不改动这些文件。
  • 风格统一：分辨率、字体、刻度方向集中在 ~/.config/mcta/config，环境变量优先。

配置入口

写法：所有设置都可写成环境变量，或写入 ~/.config/mcta/config（KEY=VALUE）， 环境变量优先。

图形参数：MT_RESOL、MT_FONT_FAMILY、MT_MATHTEXT_FONTSET、 MT_XTICK_DIRECTION、MT_YTICK_DIRECTION。

结构检索与描述符分析（mt.seek / mt.sqs / mt.skl）：MP_API_KEY（免费的 Materials Project API Key，在线检索必填）、 MT_SEEK_HOME、MT_SEEK_CONFIG、MT_SEEK_API_KEY、 MT_SEEK_PROVIDER、MT_SEEK_BASE_URL、MT_SEEK_MODEL、 MT_SEEK_MAX_TURNS、MT_SEEK_MAX_CAND，含义见 mt.seek -h。

其他工具：MT_PH_DOCS、MT_PH3_DOCS、MTSH_SCRIPTS、 PBE_PATH、LDA_PATH、GGA_PATH。

INSTALLATION

安装

通过 pip 安装，默认只含 numpy、matplotlib、ase、spglib，其余包按需追加。

命令启用的入口额外依赖
pip install mctamt、band、dos、phband、phdos、ph、ph3、shnumpy、matplotlib、ase、spglib
pip install mcta[seek]mt.seek，同时启用 mt.sklpymatgen、mp-api、scikit-learn 等
pip install mcta[skl]mt.sklscikit-learn、joblib
pip install mcta[sqs]mt.sqssqsgenerator
pip install mcta[mc]mt.mcnumba
pip install mcta[all]全部以上所有

说明

Python ≥ 3.9。未安装对应可选依赖时，命令会给出提示而不是直接报错。

电子结构 · 晶格动力学

能带与态密度

四个绘图命令共用同一套参数与出图风格：mt.band、mt.dos 处理电子结构， mt.phband、mt.phdos 处理声子谱。

mt.band · 能带

能带结构绘图：可叠加 DOS、轨道投影与自旋极化镜像图，计算有效质量，并对比两三个计算结果。

mt.band -i calc_PBE -d -z
mt.band -i calc_PBE -r -p Mo-d
mt.band -i calc_PBE -m 0.15
  • -d 在能带右侧拼接 DOS 面板，-z 生成自旋极化镜像图。
  • -p Mo-d 叠加轨道投影，-m 0.15 估算带边有效质量。
  • 传入多个目录即可并排比较不同泛函或不同磁序的结果。

mt.dos · 态密度

独立的态密度图，能量在横轴；可切换为与能带面板一致的纵向排布，支持投影与填充。

mt.dos -i calc -p d -x 0 30
mt.dos -i calc -o PDOS.png -z
  • -p d 绘制 d 轨道投影，-x 0 30 限定能量窗口。
  • -z 旋转为纵向排布，与 mt.band 的拼图风格一致。

mt.phband · 声子能带

声子能带绘图：可附 DOS 面板、对光学支做断轴处理，支持多个 BAND.dat 并排比较。

mt.phband -i BAND.dat -l g m k g -d
mt.phband -B 23 100 -y -2 110
  • -l g m k g 按给定顺序标注高对称点。
  • -B 23 100 设置断轴区间，避免低频声学支压扁光学支。
  • -d 附上声子态密度，-y 指定频率范围。

mt.phdos · 声子态密度

读取 phonopy 的 projected_dos.dat 或 total_dos.dat，绘制声子态密度。

mt.phdos -i calc -z -x 0 0.6
  • -x 0 0.6 限定频率范围，单位与 phonopy 输出一致。
  • -z 切换为纵向排布，方便与 mt.phband 对齐。
命令词库 · 中英文解释

mt.ph / mt.ph3

查 phonopy 与 phono3py 的用法：w 给英文解释，W 给中文解释，不带词条时列出全部条目。

常用命令

mt.ph w
mt.ph w --dim BAND_LABELS
mt.ph3 W --br --symfc

要点

  • mt.ph 覆盖 phonopy，mt.ph3 覆盖 phono3py，词条与本地安装的版本对应。
  • 可一次查多个词条，如 BAND_LABELS、--dim、--br。
  • 除查词外，也保留扩胞、力常数、能带、热导率等步骤的流程命令。
结构数据 · 检索 / 生成 / 分析

mt.seek / mt.sqs / mt.skl

三者共用同一工作目录：mt.seek 检索并导出结构，mt.sqs 生成准随机固溶体，mt.skl 对导出的清单做描述符分析。

mt.seek · 结构检索

从 Materials Project 检索结构，导出 CIF / POSCAR / JSON 与计算模板，并支持对本地数据集去重、筛选与打包。

mt.seek -c Ti-C -k 3 -n ti-c
mt.seek -r -D 8 -o my-pick
  • -c 指定元素组合，-k 限定返回数量，-n 设置数据集名称。
  • 需要在配置中提供 MP_API_KEY，这是唯一需要联网的命令。

mt.sqs · 准随机固溶体

读入原胞，按目标成分随机化指定子晶格，输出结构文件与成分统计。

mt.sqs -c cell.vasp -a "Cu:0.5,Au:0.5" -x 4,4,4 -n cuau-sqs
  • -a 按 “元素:占比” 描述目标成分，多个元素用逗号分隔。
  • -x 4,4,4 指定超胞尺寸，-n 指定输出名称。

mt.skl · 描述符分析

读取工作根下各导出包 <name>/manifest.csv，用随机森林做 ehull 与 band_gap 回归和 5 折交叉验证，结果写入 ml/。

mt.skl
mt.skl --home proj
  • 在工作根目录下扫描 <name>/manifest.csv（由 mt.seek / mt.sqs 就地导出），--home 可改根目录。
  • 输出特征重要性与基础评分，适合在建模前做一轮粗筛。
数值模拟 · 蒙特卡洛

mt.mc

磁性材料的蒙特卡洛模拟：内置方格、三角、双层、简立方与五种二维 XY 晶格，也可从任意晶体结构建模；支持 Ising、海森堡与 XY 模型、并行链与副本交换。

常用命令

mt.mc -x 128 -y 128 -t 0 40 2 -C 6 -S 42
mt.mc -s POSCAR -A Fe -D 2.7 3.2 -x 2 -y 2 -z 2
mt.mc -c xy-square -x 64 -y 64 -p 1 -t 5 20 0.5 -S 42

要点

  • -t 0 40 2 按起始、终止、步长扫描温度，也支持单独列温度点（-t 0 10 20 30）或反向范围（-t 40 0 -2）。
  • -C（--chain）设置并行推进的独立蒙特卡洛链数：默认 0 表示自动匹配线程数；值大于 1 时每条链从不同随机初态独立运行，最终取所有链的系综平均，等价于"多次独立重复实验取平均"，显著降低统计噪声。若同时使用 -W 副本交换，链数必须与温度点数相等。
  • -S（--seeds）固定随机种子：给定后所有随机数（初态、Metropolis 接受/拒绝）都由该种子决定，在相同输入和代码版本下结果完全可复现，便于论文审稿和调试。默认不指定，每次运行产生不同结果。
  • -s POSCAR -A Fe -D 2.7 3.2 从结构建模并设定交换耦合：-A Fe,Co 指定磁性元素（或自动探测 d/f 族），-D 2.7 3.2 按距离分段设置交换积分 -J/-K。
  • -c xy-square 启用二维 XY 模型，还有 xy-triangular、xy-honeycomb、xy-kagome、xy-diced 四种构型；用螺旋度模数 Υ 与普适跳变 2kBT/π 的交点确定 BKT 转变温度，并统计最小环上的涡旋密度。-T 10 可在重绘日志时额外画出 10 K 的涡旋状态箭头图。
脚本助手

mt.sh

按短名运行随包附带的 bash 脚本：应变扫描、超胞、对称性分析等；本地同名脚本优先于内置脚本。

常用命令

mt.sh x POSCAR
mt.sh kb POSCAR 2 2 1
mt.sh sy POSCAR

要点

  • x 应变扫描，kb 构造超胞，sy 做对称性分析。
  • 当前目录存在同名脚本时优先使用，便于本地定制。
文件与终端 · 浏览器界面

mt.server

在本地开一个网页服务：浏览目录、编辑文本、查看图片；以当前用户身份运行，文件浏览限定在运行目录内，并在页面里使用和 SSH 一致的交互式终端。

常用命令

mt.server
mt.server -p 8080
mt.server -L 0.0.0.0
mt.server -f
mt.server -o run.log
mt.server -S

参数

  • -v/-V/--version 显示版本；-h/--help 显示帮助。
  • -p/--port 监听端口，默认 9068。
  • -f/--serve 在当前终端里直接运行服务（默认转入后台）；-S/--stop 停止后台服务，-S --all 停止当前用户所有端口的服务；--status 列出当前用户所有端口上运行的 mt.server。
  • -N/--no-token 不启用 token 鉴权，直接用地址和端口访问；-L/--host 监听地址，默认只监听本机 127.0.0.1，也接受 ::1、:: 等 IPv6 地址。这两项都要在终端输入 yes/YES 才能启动，同时使用时需输入两次。
  • -o/--log [PATH] 输出日志文件；默认不写日志。-o 不带参数时写到当前目录的 mcta-server-<端口>.log，也可给出目录或文件名，已存在的同名文件会被覆盖。
  • 3D 查看器的键粗、深度雾、晶胞棱，可在结构窗口空白处右键打开的“样式设置”弹窗中调整；左下角坐标轴的长度、颜色和样式在坐标轴区域右键调整，它只跟随结构旋转、长度固定。修改即时生效；在原子上右键可单独调整该原子的颜色和大小。

要点

  • 启动后打印带随机 token 的地址（形如 http://127.0.0.1:9068/?t=…）；所有请求都要校验该 token，每次重启都会换新，旧链接立即失效。链接本身就是访问凭据，请勿分享。
  • 不需要登录：服务以当前用户身份运行，文件浏览、编辑与下载限定在运行 mt.server 时所在的目录内（终端仍是完整的 shell，可自行切换目录）。同一端口再次启动会先停止旧服务，残留的 PID 记录会自动清理。
  • 默认在后台运行；启动它的终端关闭或退出后，服务会自动停止。需要一直运行时，用 -f 在终端里直接运行，或放进 tmux / screen 中。
  • 左侧栏里是真实的 PTY shell，和 SSH 登录一致，也从同一目录起步；终端切换目录时文件列表会同步跟随（起始目录外显示绝对路径），目录每 2 秒自动刷新。
  • 目录中的图片按数量排列：1 张居中显示，尺寸与 2 张时每张相同；2 张平分一行，3 张及以上按视口宽度排布；支持 PNG、JPG/JPEG、GIF、WebP、BMP、ICO、SVG，TIF/TIFF 无法预览，按普通文件下载。
  • 结构文件与轨迹可直接在浏览器里查看（3Dmol.js）：默认正交投影，可一键切到透视；支持沿 x/y/z 轴按固定角度旋转、按比例缩放、重置视图，以及 1×–8×（默认 4×）分辨率导出 PNG / JPEG / WebP 图片。多帧轨迹可播放、逐帧拖动并选择 0.5×–4× 速度，最多读取 300 帧。
  • 默认只监听回环地址；命令以当前用户权限执行，请勿把带 token 的链接或端口暴露到外网。
